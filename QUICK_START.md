# 🚀 Quick Start - 3 Steps to Launch

## Step 1: Add Your Photo
1. Remove background from your photo using [remove.bg](https://www.remove.bg/)
2. Save as `public/profile.png`

## Step 2: Update Your Info
Edit these files with your information:
- `src/components/Hero.tsx` - Name, title, bio
- `src/components/About.tsx` - About text, skills
- `src/components/Contact.tsx` - Email, social links
- `src/data/projects.ts` - Your projects
- `src/data/caseStudies.ts` - Project details

## Step 3: Run the Site
```bash
cd react-portfolio
npm run dev
```

Visit **http://localhost:3000** 🎉
