# Project Images

## Adey Coffee Image

Please save the Adey Coffee hero image as `adey-coffee.jpg` in this folder.

The image should show the coffee brewing scene from your Figma design.

**Image requirements:**
- File name: `adey-coffee.jpg`
- Format: JPG or PNG
- Recommended size: 1200x800px or similar
- Should be the hero/main image from the Adey Coffee design

Once added, the image will automatically display in the portfolio!
